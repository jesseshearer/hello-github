# Currency Converter 

This is a simple Python script that converts different currencies (Pesos, Soles, Reais) into U.S. Dollars based on fixed conversion rates.

## Description

This project asks the user how many Colombian pesos, Peruvian soles, and Brazilian reais they have, and calculates the total value in USD.

## Requirements

- Python installed (version 3.13 or newer)
- Ability to run Python scripts from a terminal/command line
